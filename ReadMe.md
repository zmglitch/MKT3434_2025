Z-ML GUI that is the short name for the gui 

--This machine learning workflow application built with Python, PyQt6, and scikit-learn. 
   It has features like :
   1-Data Preprocessing  
   2-Regression Models
   3-Loss Functions
   4-Classification Models

--requirement to run this gui code :
   -Python 3.8+
   -PyQt6
   -NumPy
   -Pandas
   -Scikit-learn
  **to get this libraries go to terminal select new terminal and type pip install (library name)
   example : pip install PyQt6 

--Usage Guide:
  Load Dataset: Click "Load Dataset" and select a CSV file
  Choose Imputation Method: Select how to handle missing data
  Select Regression Model: Pick from available regression models
  Choose Loss Function: Determine model performance metric
  Train Model: Click "Train Regression Model"
  View Results: Check results section
